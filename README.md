# 📚 SnapStudy – AI Study Assistant

SnapStudy is an AI-powered study assistant built with Streamlit and Google Gemini.

## ✨ Features

- 📸 Upload questions, diagrams, or notes
- ✍️ Ask study questions using text
- 🤖 AI-powered explanations using Gemini
- 🎯 Multiple answer styles
- 🧠 Explain More
- 📝 AI-generated quizzes
- 📑 AI-generated notes
- 🃏 AI-generated flashcards
- 💬 Follow-up questions
- 📚 Study history
- 📥 Download answers
- 📧 Send study material by email
- ⏱️ Live study timer
- 📊 Study dashboard

## 🛠️ Technologies Used

- Python
- Streamlit
- Google Gemini API
- Google GenAI SDK
